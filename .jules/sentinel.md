## 2024-10-17 - Removed global ALLOWALL from X-Frame-Options
**Vulnerability:** The application globally configured `config.action_dispatch.default_headers = {"X-Frame-Options" => "ALLOWALL"}`, completely disabling Rails's default clickjacking protection (`SAMEORIGIN`) across all endpoints.
**Learning:** This was likely done because certain pages (specifically `OrganizationsController#show` with the `iframe` param) were designed to be embedded in iframes. Instead of making the security exception granular, a global change was applied, making the entire application vulnerable to clickjacking.
**Prevention:** Avoid modifying global security headers (like `config.action_dispatch.default_headers`) to support a single feature. Instead, rely on secure defaults (e.g., `SAMEORIGIN`) and selectively remove or overwrite headers (e.g., using `response.headers.delete("X-Frame-Options")`) only in the specific controller actions and conditions that require an exception.
